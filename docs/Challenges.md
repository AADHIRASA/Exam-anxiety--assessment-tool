# Challenges which I faced

##### Overview of challenges:

Much of the coding on this project wasn't writing something new but rather it was figuring out why something wasn't working and fixing it. Here are the main challenges faced and how each one was rectified

# 1. Getting the Logic Right in Python

The scoring logic broke a few times because of how Python has the black spaces in the start of the code. Once I could understand it better, the scoring worked.

# 2. Git Merge problem

Editing code from two different places at once caused a big problem in Git, where two versions of the same file didn't fully match. I fixed it by choosing the correct version and finishing the merging properly. This made me realise to just edit the code in one place instead of two.

# 3. Code Getting Overwritten

A couple of times, working code was accidentally replaced by an older version. Each time  it was recovered using Git's history page which keeps a record of every old version of the code.

# 4. A Server Error After Deployment

After putting the app online, it stopped working for sometime cause of a server error. Checking the server's error log showed the actual problem which happened to be a settings mistake. I quickly fixed it directly in the hosting configuration.

# 5. Choosing the Right Hosting Option

A couple of free hosting options were compared before deciding. One was more convenient but would have quietly lost saved data over time. The one I chose ended up being the safest but I got to check it every month for it to work.

# 6. File and Folder Mix-ups

While adding styling, a file got created in the wrong format (as a folder instead of a file), which stopped the styling from working. This was fixed by figuring out the location of the file and then moving it to the right place.
